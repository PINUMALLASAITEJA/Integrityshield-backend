# IntegrityShield – Role-Based Student Activity Monitoring Platform

IntegrityShield is a real-time classroom activity monitoring platform designed to maintain academic integrity in computer laboratories and digital learning environments. The system enables faculty members to supervise active student sessions, detect unauthorized application usage, and receive real-time violation alerts while preserving user privacy.

---

## Features

- Role-Based Authentication for Students and Faculty
- JWT-Based Secure Session Management
- Real-Time Process & Active Window Monitoring
- Unauthorized Application Detection
- Rule-Based Violation Detection System
- Centralized Faculty Monitoring Dashboard
- Structured Activity Logging & Session Tracking
- Privacy-Focused Monitoring (No Screen Capture)
- PostgreSQL-Based Persistent Data Storage

## Workflow

1. Faculty starts a monitoring session
2. Students log in using authorized credentials
3. Student desktop client activates monitoring
4. Running applications and active windows are tracked
5. Unauthorized activities are detected using predefined rules
6. Violations are logged and reported to faculty dashboard in real time
